## The name

"Chieftain" is the name of this project. Neither licence grants any right to use the project
name, or to present a derivative work as being Chieftain.

This matters more than it might seem. The project's design rules — nothing redeemable, no
near-miss animation, no manufactured urgency, the house edge always a visible cost — are the
reason it exists. An open-source licence cannot restrict how the code is used; the Open Source
Definition forbids that, and it is a rule worth keeping. So the code is free to fork, including
by people who strip those rules out. What they may not do is call the result Chieftain.
